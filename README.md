## Запуск проекта

### Фронтенд

```bash
npm install
npm run dev
```

Приложение будет доступно по адресу http://localhost:5173

### Моковый бэкенд (json-server)

В отдельном терминале:

```bash
npm run server
```

Сервер поднимается на порту 3000

### Сборка

```bash
npm run build
```

### Линтинг

```bash
npm run lint
npm run format
```
